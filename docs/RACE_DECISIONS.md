# Mezoria — Race Decisions

Race design reference and approval index. The full structured race, tribe, clan, aspect, ability, and movement data is stored in [`../data/races.json`](../data/races.json). This file is a readable guide; use that data file for complete mechanics.

## Roster and racial specifications

### Human

- **Attributes:** Choose 3 distinct attributes, +2 percentage points each.
- **Base movement:** 5.
- **Traits:** Adaptable: Choose three distinct attributes; each increases by 2 percentage points (e.g. 35% to 37%).; Versatile: Gain one additional Skill Talent of choice at character creation.; Essence Affinity: Gain 5% additional Essence from all sources..

### Sylvan

- **Attributes:** +3 Prowess; +3 Presence.
- **Base movement:** 6.
- **Traits:** Nature Resistance.
- **Abilities:** Forest Stride.

### Embergiest

- **Attributes:** +3 Might; +3 Endurance.
- **Base movement:** 4.
- **Traits:** Fire Resistance.
- **Abilities:** Bare-Handed Forging; Master of the Forge; Burning Strikes.
